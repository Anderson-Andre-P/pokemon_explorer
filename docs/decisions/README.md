# Architecture Decision Records

One file per decision: `NNNN-kebab-title.md`, with `# NNNN. Title`, a date, a
status, and **Context / Decision / Alternatives / Consequences**.

Status values: `Accepted`, `Superseded by NNNN`, `Amended by NNNN`. Never edit
an accepted decision's substance — write a new ADR that supersedes or amends
it.
